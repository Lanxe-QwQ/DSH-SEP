# DSH SEP 0.2.1-beta.5

DSH 固定为 0.2.1-rc.2。SEP 为 Beta；Windows Full/Only、Linux x64、macOS ARM64 四份安装归档由同一已审记忆修复输入重建，平台范围仍为限定环境预览。

## 修复

1. 查询、相似召回、注入上下文与去重不再刷新 lastUsedAt。只有受控明确确认、更正或重新启用才续期，同一会话消息不能更换工具事件重复续期。满500条时，在同事务中归档符合退出条件的内容后再接纳；保护项不会为腾位被删除。
2. BM25 汉字双字只来自原文连续汉字段，不跨标点、英文、数字、空白或 emoji；按 Unicode 码点处理。保留合法单字与 Segmenter 词项，不能据此保证所有语义匹配都正确。
3. 冲突对方已合法退役时可刷新关系并重新审阅确认。旧修订返回刷新要求；未知、跨域或损坏删除依据仍拒绝，不再用抛错回滚刚持久化的关系修复。

不清空记忆、索引、账本或预算；无法重建过去被误刷新的真实使用时间，也不自动降级覆盖新业务数据。

## 安装与限制

本版按全新独立安装交付；不是通用原位升级候选。Only需要精确匹配的官方来源；不能向任意官方桌面目录直接覆盖安装。保留旧实例与原数据，勿把新安装当成自动迁移授权。

macOS重新构建 app/安装器、ad-hoc签名，不含Developer ID或公证。完整跨平台公开认证、付费模型、物理输入与同次公网自动安装正例仍未完成。具体本轮样本、失败及补跑以 VERIFICATION.json 为准，不把历史测试或不同平台样本相加冒充独立覆盖。

历史输入文档中“未上传”“Mac未运行”“候选”的时点词保留为当时记录；本版范围以本目录、构建回执与当前安装资产哈希为准。日常版此次没有切换。
